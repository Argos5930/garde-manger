# Garde-manger

Application web installable (PWA) de cuisine et de nutrition, en français, sans compte ni IA payante.

- Budget calories sur la semaine (Mifflin-St Jeor) et marge plaisir
- 96 recettes filtrables par niveau, temps, saison, avec note calculée selon la méthode Nutri-Score 2023
- Scan de code-barres et alternatives mieux notées via Open Food Facts
- Analyse d'habitudes alimentaires d'après la table Ciqual et les repères du PNNS
- Import de recettes par copier-coller ou par le bouton Partager d'Android
- Liste de courses par rayon selon le magasin, mode frigo, plan de batch cooking, calendrier de saison

Toutes les données personnelles restent dans le navigateur du téléphone (localStorage).
